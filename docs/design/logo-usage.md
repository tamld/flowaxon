# flowaxon logo usage

The mark: a containment ring with a gate gap, a signal tail arriving from
outside, and one amber proof packet crossing the boundary toward the core.
It is the site's own hero interaction, compressed into one glyph.

## Files (assets/brand/)
- logo-mark.svg — primary glyph, ink + amber (light ground)
- logo-mark-mono.svg — single-color variant, uses currentColor (any ground)
- logo-horizontal.svg — mark + "flowaxon" wordmark (Georgia) + LDT tag
- logo-stacked.svg — mark above wordmark
- favicon.svg (32 grid), icon-16/32/180/512.png, root favicon.ico + apple-touch-icon.png

## Rules
- Clearspace: one ring radius (24 units) on all sides of the mark.
- Minimum size: 20px (mark), 120px width (horizontal lockup).
- Amber (#8a5c06 light / #f0a832 dark) is the ONLY accent — it marks the
  proof packet, nothing else. Ink: #16191f on light, #eef4fb on dark.
- Do not: rotate the mark, add gradients, recolor the ring, put the packet
  outside the ring, or set the wordmark in another face.
- On dark grounds use logo-mark-mono.svg with color set to a light ink.
