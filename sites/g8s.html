quickstart — g8s supervisor loop go 1.22+ • sqlite-wal
# 1. Build & verify local harness health
$ make local && ./bin/g8s doctor --json
# 2. Issue a single-use path-scoped WriteReceipt (F0 Only)
$ REC=$(./bin/g8s receipt issue --path "internal/worker/*.go" --ttl 1800 --json | ./bin/g8s select data.receipt_id)
# 3. Submit bounded F1 worker task & execute in isolated Git worktree
$ TASK=$(./bin/g8s submit --idempotency-key slice-01 --permission workspace_write --role implementer --provider 9router --model deep-coding --receipt-id "$REC" --prompt "..." | ./bin/g8s select data.task_id)
$ ./bin/g8s worker --once --provider 9router --model deep-coding
# 4. Verify mechanical evidence & deliver worktree diff
$ ./bin/g8s verify --task "$TASK" --json && ./bin/g8s deliver "$TASK" --prune-worktree
Target Personas & Value Delivery

Built for 3 Distinct Engineering Consumers

Zero-Trust Delegation • Zero Quota Waste
1. AI Agent & Harness Engineers Builder / Operator

Stop Frontier Brain Quota Burn (Lesson #23)

Cloning your frontier F0 Brain model (Claude Opus / Gemini Pro) across N subagent coding loops burns your 5-hour quota to 0%. g8s keeps F0 strictly for reasoning and dispatches F1 coding/scouting loops through 9router SWE combos (deep-coding, reasoning-high, fast-agent).

✓ Outcome: 10× parallel worker throughput with 0% F0 quota exhaustion.
2. Platform & Security Architects Governance / Auditor

Eliminate Out-of-Scope Agent Mutations

Prompt instructions cannot stop a hallucinating agent from editing .env, CI workflows, or sibling packages. g8s enforces in-process WriteReceipt.AllowedPaths globs, SHA-256 CAS file guards, and kernel firewall strata (E_S1_DIRECT_MUTATION_FORBIDDEN).

✓ Outcome: Mathematical 1-1-1 boundary (1 Issue = 1 Worker = 1 Receipt).
3. Multi-Repo Maintainers & Leads Consumer / Adopter

Pull-Based Offer Bundle & Double-Blind QA

Onboard any repository in 60 seconds with g8s offer init across 4 domain profiles (knowledge, security, infra, utility) and defeat AI reviewer sycophancy using S3-A BlindAdjudicator verification packets.

✓ Outcome: Repo-agnostic CI spec-sync gates & sanitized Mode-3 defect packets.

Ring F0 — Sovereign Brain

Exclusive holder of architecture authority, git commits, vault promotion, and WriteReceipt issuance (Operator ↔ F0 = 1-1).

Spawned via g8s worker with SQLite WAL CAS lease, isolated Git worktree, killable OS PGID, and zero horizontal F1 ↔ F1 edges.

Ring F2 — Bounded Subagent

Spawned inside F1 (F2 ⊆ F1 ⊆ F0), inheriting G8S_RECEIPT_ID and G8S_SCOPE_ROOT. Invisible to F0 except via F1's sealed evidence.
