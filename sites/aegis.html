Who Relies on Aegis Defense-in-Depth?

Deterministic Code Over Probabilistic Prompts
1. Autonomous SREs & Infra Ops Operator

Physical Brake on Destructive CLI Commands

Allow AI troubleshooting agents to inspect logs, run pct status, or query VictoriaLogs freely — while physically freezing high-blast-radius mutations (kubectl delete, zfs destroy, firewall edits) until you tap Approve on your phone.

✓ Outcome: Autonomous speed for read/triage; human sovereignty for mutations.
2. SecOps & AppSec Engineers Defender

Defeat Indirect Prompt Injection to RCE

When an agent reads untrusted web pages, logs, or GitHub issues containing hidden shell payloads (curl ... | sh, base64 exfiltration), Aegis L1 AST analysis catches chained pipes and subshells before execution.

✓ Outcome: Zero blind execution of untrusted remote payloads.
3. Compliance & Public Open-Source Teams Auditor

Cryptographic Non-Repudiation & Zero-Leakage DLP

Every HITL callback is signed with HMAC-SHA256 (timestamp + nonce + command hash) to prevent replay attacks, and every git commit passes 8 deterministic DLP gates blocking private IPs and secrets.

✓ Outcome: 100% sanitized public commits & tamper-evident audit logs.
